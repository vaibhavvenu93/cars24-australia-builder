# CARS24 Australia — Business Builder OS

An outside-in operating prototype built for the CARS24 Australia Business Builder application.

**Live prototype:**  
https://cars24-australia-os.streamlit.app

> This is not a proposed CARS24 product and does not use confidential CARS24 information.  
> All operating data is synthetic. The purpose is to demonstrate how I would approach the Australia business: research the system, model the economics, identify constraints, prioritise interventions, and build tools that help operators act.

---

## Why I built this

The role asks for someone who can operate roughly:

**50% strategy + problem solving**  
**50% execution + outcomes**

Rather than only writing why I would be a good fit, I treated the application as a small version of the job itself.

I started with the question:

> If I joined CARS24 Australia tomorrow, what would I need to understand before deciding what to build or change?

The answer was not "another dashboard."

I wanted a system that could move through:

**Evidence → Economics → Diagnosis → Decision → Simulation → Prioritisation → Execution**

That became the Builder OS.

Every vehicle is a capital-allocation decision moving through a lifecycle:

  ↓
Inspect
  ↓
Refurbish
  ↓
Price
  ↓
Locate
  ↓
Market
  ↓
